# lhg-amz-keywords：关键词与 Search Terms 方法论

> 目标：把 250 字节的 Search Terms 用满、用准——无重复、低重叠、全是标题没覆盖的长尾词。
> 核心纪律：**标题负责大词，Search Terms 负责捡漏；重复与 ASIN 是红线。**

## 1. 何时使用

- 新品 Listing 要定关键词 → 走全流程
- Search Terms 被截断/无效 → 按第 3.3 节重编
- 自然流量起不来 → 按第 3.4 节诊断

## 2. 输入与输出

**输入：**

| 输入项 | 说明 |
|---|---|
| 产品信息 | 品类、参数、场景（越全词越多） |
| 标题 | 已定标题（用于计算重叠率） |
| 竞品 Listing（可选） | 只参考其"词的方向"，不许抄词堆 |

**输出：** 核心关键词清单（2-3 个）+ Search Terms（≤250 字节）+ 词表说明。

## 3. 分步方法论

### 3.1 四类词挖掘

| 类型 | 定义 | 放哪里 | 示例 |
|---|---|---|---|
| 核心关键词 | 品类大词，2-3 个 | 标题 + Search Terms | 保温杯、大容量水杯 |
| 长尾词 | 参数词+场景词 | Search Terms 主力 | 316不锈钢、办公室大水杯 |
| 人群词 | 使用人群 | Search Terms | 学生党、上班族 |
| 排除词 | 竞品品牌、ASIN | **哪里都不许放** | — |

**挖掘方法：** 从产品参数表逐行提词（材质→材质词，容量→容量词，场景→场景词）；再从目标人群的生活场景提词。提完按"与产品相关度"排序，砍掉后 30%。

### 3.2 核心关键词选择

- 选 2-3 个：1 个品类大词 + 1-2 个带参数的精准词
- 标准：与产品强相关、能进标题、读起来像人话
- **不许编造搜索量**：没有数据的"月搜 10 万"不许写，不确定就写"待验证"

### 3.3 Search Terms 编制五规则

1. **≤250 字节**（UTF-8）：中文 1 字 = 3 字节，实际能放约 80 个汉字。超了会被截断，截断=白写（审计规则 AMZ-KW-001）。
2. **去重**：同一词出现 2 次即浪费（审计规则 AMZ-KW-002）。单复数、大小写变体也算重复。
3. **低重叠**：与标题重叠率 ≤50%（审计规则 AMZ-KW-003）。标题已有的词不许再写，优先补长尾词与场景词。
4. **禁 ASIN**：Search Terms 里出现 ASIN 直接判操纵排名（审计规则 AMZ-KW-004，blocker）。
5. **禁品牌词**：自己的品牌词（已备案）可放 1 次；竞品品牌词 1 个都不许。

**编制顺序：** 长尾词 → 场景词 → 人群词 → 核心词补位（标题没覆盖的），按相关度从高到低排，排满 250 字节即止。

### 3.4 自然流量诊断

| 现象 | 查什么 |
|---|---|
| 有展示无点击 | 标题与主图问题，不是关键词问题 |
| 展示量低 | 核心关键词是否太偏，或 Search Terms 全是标题重复词 |
| 来了错误流量 | Search Terms 里有不相关的词，删掉 |

### 3.5 迭代节奏

- 上架后 4 周内不动 Search Terms（等数据）
- 按搜索词报告补高转化的词、删只花钱不转化的词
- 每次改完记录日期与改动，复盘时可追溯

### 3.6 词表模板（可直接套用）

```markdown
## 核心关键词

(品类大词1), (品类大词2), (精准词1)

## Search Terms

(长尾词1),(长尾词2),(场景词1),(场景词2),(人群词1),(人群词2)
```

**填写顺序：** 先填核心关键词（进标题），再按"相关度从高到低"填 Search Terms，
填满 250 字节即止。填完后跑一遍审计脚本确认五规则全绿。

### 3.7 新人最常问的 5 个问题

1. **Q：Search Terms 要不要加复数/单数两种？** A：不要，算重复，浪费字节。
2. **Q：品牌词能放吗？** A：自己的品牌（已备案）放 1 次；竞品品牌 1 个都不许。
3. **Q：中文词和英文词混放吗？** A：目标站点用什么语言就用什么语言，不混放。
4. **Q：词越多越好吗？** A：不是，250 字节内"相关度高"优先，凑数词拉低流量质量。
5. **Q：抄竞品的词行吗？** A：方向可参考，逐词照抄=把竞品的错误也抄来，且可能含其品牌词。

### 3.8 季节性词管理

| 季节 | 加词方向 | 示例 |
|---|---|---|
| 夏季 | 冷饮/户外 | 冷萃杯、户外便携 |
| 冬季 | 保温/送礼 | 长效保温、送礼佳品（放五点，不放标题） |
| 开学季 | 学生 | 学生党、宿舍 |

**规则：** 季节词只进 Search Terms，不进标题（标题换了影响权重）；
过季后及时删掉，保持 250 字节里全是当季有效词。

### 3.9 词库维护

| 周期 | 动作 |
|---|---|
| 每月 | 按搜索词报告补高转化词、删无效词 |
| 换季 | 换季节词（见 3.8） |
| 大促前 2 周 | 加大促相关词（black friday 等，注意只放当季） |

**词库文件：** 维护一份 `keywords-YYYYMM.md`，记录每批词的"加入日期/来源/表现"，
换人接手也能看懂。不维护的词库，半年后就是一堆过时垃圾词。

## 4. 反模式（这些做法一定错）

1. **Search Terms 复制标题**：重叠率 90%+，250 字节全浪费。
2. **堆 ASIN 引流**：写竞品 ASIN 蹭流量——违规，抓到就下架。
3. **编造搜索量**："这个词月搜 50 万"没有数据支撑——误导自己。
4. **一个词写 5 遍**：重复不会加权，只会浪费字节。
5. **放无关大词**：卖保温杯放"水杯"的上位词"厨房用品"——来的全是错误流量，转化率被拉低。
6. **超 250 字节硬塞**：超限部分直接丢弃，还不如精简后全量生效。

## 5. 自检与反馈

**质检门（Search Terms 发布前逐项打勾）：**

- [ ] ≤250 字节（UTF-8 实测）
- [ ] 无重复词（含单复数/大小写变体）
- [ ] 与标题重叠率 ≤50%
- [ ] 无 ASIN、无竞品品牌词（跑审计脚本 AMZ-KW-001/002/003/004）
- [ ] 每个词都与产品强相关，无关大词已删
- [ ] 未编造任何搜索量数字

**标准冒烟用例：** 用 `fixtures/amazon-bad/listing.md` 跑审计脚本，应命中 AMZ-KW-001 / AMZ-KW-002 / AMZ-KW-003 / AMZ-KW-004；用 `fixtures/amazon-good/listing.md` 跑，应零 warning。
